# MoneyMap 💰

### A Smart Personal Finance Dashboard for Gen Z

MoneyMap is a personal finance web application designed to help users manage a ₹10,000 budget over 30 days. It provides a clear view of spending, savings goals, upcoming commitments, and projected balances.

## 🎯 Problem Statement

Young adults often struggle to manage limited budgets, track daily expenses, and prepare for unexpected costs. MoneyMap helps users understand their financial position and make informed spending decisions.

## ✨ Features

- **Dashboard:** View available balance and overall financial health.
- **Budget Tracking:** Monitor spending against the available budget.
- **Transactions:** Review and manage recorded transactions.
- **Savings Goals:** Track progress towards financial goals.
- **30-Day Forecast:** View projected balances over the budgeting period.
- **Decision Simulator:** Explore how spending decisions affect the remaining budget.
- **Subscriptions:** Review recurring expenses.
- **Unexpected Expenses:** Consider emergencies and their impact on finances.
- **Responsive Interface:** Designed for desktop and mobile screens.
